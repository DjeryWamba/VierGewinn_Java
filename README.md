Vier Gewinnt

Das Spiel „Vier Gewinnt“ als Java-Konsolenanwendung.

Spielregeln

Zwei Spieler werfen abwechselnd einen Stein in eine Spalte (6 × 7 Felder). Wer zuerst vier Steine in einer Reihe hat (waagerecht, senkrecht oder diagonal), gewinnt. Sind alle Felder voll, ist das Spiel unentschieden.

Menü

Zwei Spieler
Programm beenden
